Email → Appointment

Outlook add-in: open an email, press one button, get a prefilled calendar appointment (subject, meeting link, body). You add attendees and save.

Install

  1. Download the manifest: manifest.xml
  2. Outlook on the web / new Outlook: Settings → General → Manage add-ins → My add-ins → Add a custom add-in → Add from file → pick the downloaded file.
  3. Classic Outlook desktop: same dialog, reachable from Get Add-ins on the ribbon.
  4. Open any email → Email to Event button on the ribbon.

Source: github.com/autoMantis/office_events
